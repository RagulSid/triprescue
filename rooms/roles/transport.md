# Role: transport

**Holder:** `transport-agent`
**Room:** any Parvati disruption room (named by the scenario)

## Job

- Find replacement vehicles for the cancelled leg.
- Use the supplier sheet first. Label those options CONFIRMED.
- Anything from search is ADVERTISED ONLY. Never call it confirmed.
- For each option give: vehicle, seats, departure, arrival, cost, label.
- Mark any option over the room's 25,000 INR cap BLOCKED BY CAP, with the numbers.
- Answer knock-on questions from the itinerary agent (for example, whether a later departure can move).
